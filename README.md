## 👋 About me

Backend-heavy full stack developer with **4+ years** building web applications end to end — from the database schema and queued jobs to the screens people actually use. Most of my work lives in **Laravel**, **Magento 2** and **NestJS**, backed by **PostgreSQL** and **MySQL**.

What I care about is the part that comes after launch: clear module boundaries, migrations that are safe to run twice, permission models that hold up when a new role appears, and tests that catch a regression before a client does.

- 🔭 **Currently building** a NestJS service marketplace API — payments, credits, role-based access and file handling
- 🧰 **Happy owning a feature end to end**, from migration to Swagger docs to e2e test
- 🌱 **Going deeper on** Docker, deployment automation and observability
- 💬 **Ask me about** Laravel queues and cron, Magento 2 customisation, or structuring a NestJS module
- 🤝 **Open to** backend and full stack collaboration

## 🚧 Currently building

**CollaboConnect** — a service marketplace API on **NestJS 11 + TypeORM + PostgreSQL**, where seekers post jobs and providers unlock them with credits.

| Area | What went into it |
| --- | --- |
| Access control | Super admin, sub admin, seeker and provider roles with per-module permission matrices |
| Payments | Stripe Checkout credit packages, webhook-driven ledger and balance history |
| Files | Two-step token uploads, per-entity size and mime rules, ownership resolved per record |
| Workflow | Service requests moving through review, open, deactivated and completed with milestone stamps |
| Quality | Swagger docs, reversible migrations, Vitest unit + e2e suites behind coverage gates |
